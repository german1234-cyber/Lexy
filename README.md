# Lexi — мобильный словарь английского

Рабочий React + Vite прототип по референсам.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).
Для сборки: `npm run build`.

## Что работает
- Добавление фраз по одной или списком
- Предзаполненные переводы и примеры для ряда выражений, редактирование вручную нажатием на слово
- Словарь: поиск, даты, удаление, озвучка
- Флеш-карточки и интервальное повторение (локальное)
- Упражнения с пропуском и проверкой ответа
- CSV импорт/экспорт
- Сохранение в localStorage устройства

## Ограничения
- Онлайн ИИ и автоматический перевод любых новых слов не подключены. Это требует API и бэкенда.
- Облако/синхронизация между устройствами и аккаунты не подключены.
- Озвучка использует Web Speech API браузера.
